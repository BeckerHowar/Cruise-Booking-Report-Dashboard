Cruise Booking Report Dashboard

built by Becker Howar
Driver-based three-statement model for Voltway, a fictional Energy-as-a-Service company: it installs efficiency equipment at customer sites, retains ownership, and leases it back to the customer for a fixed monthly fee — funding the build-out with an equipment debt facility. Edit any driver on the left — the P&L, balance sheet, and cash flow rebuild instantly, and the statements tie every month.
How this was built

A single self-contained HTML file — no external libraries, no network calls, no spreadsheet behind it. The finance engine is a short block of plain JavaScript (view source: “MODEL ENGINE”) that rebuilds the full monthly three-statement model on every input. I specified the driver map, statement structure, and accounting conventions first, then had the logic stress-tested for technical accounting articulation and Energy-as-a-Service industry realism before any code was written. AI-assisted build; analyst-specified logic. Every figure is synthetic.

Where this sits: Voltway is the demonstration tier of this discipline — synthetic and public-safe by design. A production build goes further than any public page should: live data import and export, reconciliation against source systems, and audit trails behind every number. That tier exists in the work; it carries real data and real methodology, so it stays private. Its concepts — ARR, cohorts, install economics — are Energy-as-a-Service language, and they are not meant to transfer to other industries; the companion Meridian model shows the same discipline rebuilt for a different operating model.
