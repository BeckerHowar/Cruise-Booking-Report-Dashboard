Cruise Booking Report Dashboard

built by Becker Howar
An 88-slide monthly booking report rebuilt as one live page for Meridian Yacht Collection, a fictional three-ship yacht line. Every view reads from a single booking table.
How this was built

Every view resolves to two tables: one row per suite booked on a voyage on a booking date, and one row per voyage carrying capacity, budget and forecast. A plain JavaScript engine computes the booking position, pace against prior years, the outlook, the profit bridge and the cash river from those two tables, and re-runs a set of integrity checks on every change — the bridge must foot to the profit gap, the river must conserve cash, and the same total must come out by ship, by quarter and by region. The badge in the control bar turns red if any of them fails.

The data source is a switch. Simulated generates a deterministic book for a fictional line, with deliberate deviations from plan so every variance has a cause. Sigma reads the same two tables from a Sigma workbook when the page is embedded there as a plugin; the column contract is under Definitions & data. No real company's figures are in this repository. AI-assisted build; analyst-specified logic.
